# VerseShell 1.0 ACI Surface

Agent integrations should call **typed operations** over JSON-RPC (`op`) or MCP
(auto-generated tool names with `.` → `_`).

## Core

| Op | MCP | Purpose |
|----|-----|---------|
| `exec.run` | `exec_run` | Argv process + observation budget |
| `result.query` | `result_query` | Artifact head/tail/grep/raw |
| `ops.list` | `ops_list` | Enumerate registered ops |

## File

| Op | Notes |
|----|-------|
| `file.view` | cursor + window |
| `file.read_range` | start/end lines, max 500 default |
| `file.hash` | `sha256:…` for expected_hash |
| `file.replace_exact` | unique match; `E_AMBIGUOUS` / `E_STALE_HASH` |
| `file.apply_patch` | ordered patches; fails closed if any miss |
| `file.edit_range` | line range replace; optional `check` |
| `file.diff` | simple line diff vs `new_text` |
| `file.remove` | agent mode → trash + `restore_token` |

## Transaction / trash

| Op | Notes |
|----|-------|
| `tx.begin` / `tx.commit` / `tx.rollback` / `tx.status` | wraps existing journal |
| `tx.restore` | `trash://…` from `file.remove` |

## Repo / Test

| Op | Notes |
|----|-------|
| `repo.search` | text search, `max_items` |
| `repo.changed_files` | git porcelain |
| `repo.summary` | branch + dirty + top-level |
| `test.discover` | cargo/npm/pytest probes |
| `test.run_target` | orchestrates `exec.run` |
| `test.summarize_last` | process-local last run |

## Observation contract

All ops return `verseshell.observation/v1` with `ok`, `data`/`error`,
`diagnostics`, `meta`, `suggested_next`.

On `E_NEEDS_APPROVAL`, `error.hint` carries the retry path (`AETHER_APPROVE=<token>`
or `approve("…")`), and `data.approval_token` may be present.

Legacy `cmd` / MCP `exec` / `eval` remain for the 1.x series as secondary APIs.

## Acceptance closed loop

The Coder Agent happy path is covered by
`tests/aci_1_0_closed_loop_acceptance.rs`:

1. `ops.list` → file view/read/hash → repo search/summary
2. `tx.begin` → edit → `tx.commit` / `tx.rollback`
3. lint / stale-hash / ambiguous failure codes
4. `exec.run` success silence + failure artifact → `result.query` raw recovery
5. `test.run_target` + `test.summarize_last`
6. `file.remove` (trash) → `tx.restore` (including across server restarts)

### Agent env for exec / tests

| Env | Purpose |
|-----|---------|
| `AETHER_MODE=agent` | Agent policy (sandbox + approval for exec) |
| `AETHER_WORKSPACE` | Workspace jail root |
| `AETHER_APPROVE_ALL=1` | CI / local auto-approve for `exec.run` / hard deletes |
| `AETHER_APPROVE=<token>` | Approve one action token from `error.hint` |

Production agents should use per-action tokens, not `AETHER_APPROVE_ALL`.

### Client notes

- Send **UTF-8 without BOM**, line-delimited JSON on stdin.
- PowerShell `Get-Content | ae --serve` may inject a BOM on the first line and
  yield `E_PARSE`; prefer raw byte writes or `cmd /c type file.jsonl | ae --serve`.
