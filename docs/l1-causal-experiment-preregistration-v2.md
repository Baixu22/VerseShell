# L1 提示长度与接口框架实验：v2 待冻结方案

修订日期：2026-09-30。**这是开发方案，尚未冻结、尚未采集，不产生确认性结论。**
本版替代未执行的 v1，旧文件保留历史。首个实验格之前须冻结协议、逐字提示、
序列化规则、分析代码及 study manifest；冻结后变更另开版本，旧数据单独保留。
C14/C16 阈值及 no-go 决定不变。

## 1. 先确认问题边界

round 14 的 D 有 15/105 格 completion 截断，其中 9 格有首轮零工具的证据；
不能把 15 格都叫作“首轮零工具”。r15 with-arm 的 D=0/105、A=0/105、A′=2/105，
两个 A′ 截断都在第 2 轮。r15 已被看过，只是开发证据，不能再注册成新确认样本。
P0-1 状态是**当前轮未复现、原因未定**，不是已修复，也不是“长度无关”。

先离线运行 `tools/live_turn_diagnostics.py`。若只是了解当前配置，用健康检查及区间
描述即可；稀少或未出现的效应可能不支持有意义的因果检验。是否新开 L1 在独立采集前
决定，不根据正式实验中途结果换臂或扩样。对历史截断任务的定向复测只能称为
“富集样本的探索性复测”，不能估计全任务集截断率。

## 2. 修正互相矛盾的长度构造

v1 要求 D-L 缩到 A0 长度，又要求 A-F 增加相同删减量后与 D-L 等长；删减量非零时
不可能同时成立。D 的工具 schema 本身也可能已长于 A0，不能靠删系统提示实现。

v2 保持每个框架内的原生系统提示、工具 schema、权限和消息组装不变，仅追加固定填充。
设原生静态前缀字符数为 `nA`、`nD`，选择共同短目标 `L >= max(nA, nD)` 和正长度差
`delta`。**L、delta 及每臂逐字文本必须在首格前定值，当前尚未定值。**

| 实验臂 | 框架 | 静态前缀目标 | 构造 |
|---|---|---|---|
| A-S | A：raw_shell | L | 保留 A 原文，追加冻结填充到 L |
| A-L | A：raw_shell | L + delta | 在 A-S 上追加冻结增量填充块 |
| D-S | D：verseshell_aci | L | 保留 D 原文，追加冻结填充到 L |
| D-L | D：verseshell_aci | L + delta | 在 D-S 上追加同一增量填充块 |

| 主对照 | 比较（前者减后者） | 问题 |
|---|---|---|
| C1 | D-L − A-L | 共同长目标下的框架差异 |
| C2 | A-L − A-S | A 框架内追加填充的效应 |
| C3 | D-L − D-S | D 框架内追加相同填充的效应 |

短目标下的框架差异、交互作用、原生 A0/D0 都是探索性问题，不纳入三个主对照。
填充没有可保证的“语义惰性”，C2/C3 首先解释为**追加这段文本的效应**。
不同框架的基底填充量不同，C1 也不能证明普遍的框架独立效应；不能进一步归因到
工具数量、某个 schema 字段或 reasoning 机制。

## 3. 长度与操作检查

匹配单位是 Python `len(text)` 的 Unicode 码点数，不使用含混的“UTF-8 字符数”；
同时记录 `len(text.encode('utf-8'))` 字节数。静态前缀为系统提示与按冻结 JSON
规则序列化的工具 schema；序列化参数、连接分隔符及填充文本都写入 manifest。
不能用观察文本的 `len//4` 代理当作端点 tokenizer。

离线先检查共同目标精确相等及 `delta > 0`。首轮端点 `prompt_tokens` 用于操作检查：
C1 两臂中位数的对称相对差 `abs(x-y)/((x+y)/2) <= 15%`；C2/C3 的长臂中位数应
高于短臂，**不对故意拉开的长短对施加等长约束**。同时报告逐任务配对差及 usage 缺失。
检查失败则限制整个对照的解释，不按事后 usage 挑掉某些格来提高显著性。
操作检查不能消除语义副作用。

## 4. 固定输入、结局与缺失

固定任务/fixture、成功谓词、模型/端点、代码/tree/工具链指纹、权限、seed 集合、
`max_turns=20`、`max_tokens=16384`、`temperature=0`、超时及重试规则。
若端点探针要求变更，重新冻结后再采集。

格身份为 `(collection_id, task_id, seed, condition, run_index)`。
**主结局**为首轮 `finish_reason == 'length'` 且 `tool_call_count == 0`。
任意轮 completion 截断、总轮数 cap、成功率、usage 和时延分别作为次要结局，不能混用。
逐轮记录 finish_reason、usage、tool_call_count、request_ms、错误与实际返回的 reasoning。
字段缺失不能记为未截断，也不能从 completion usage 推断 reasoning 长度。

端点失败保留为未知，不算模型解题失败。主分析使用完整配对的可分析集，列出缺失率
与原因，同时报告把未知结局分别置为 0/1 后对照差的最坏情形界。
300s 超时可能与长 completion 相关，不能假设缺失随机；若未知结局足以改变结论，
主张不可用。报告同时保留所有格，不能只发布可分析集。

## 5. 网格、重复与顺序

完整网格为 **35 任务 × 3 seeds × 4 实验臂 = 420 格/完整采集**，相同网格独立
采集至少 3 次，共 **1260 格**。42/43/44 是一次采集内部的 seed，不是三次完整重复；
这 1260 格也不是独立同分布样本。旧文“6 个单向不一致对可使 McNemar 显著”只是
特殊数据下未校正的拒绝阈值，**不是 5.7% 的 MDE 或功效证明**。

首格前须用冻结效应目标、任务/采集相关性及缺失情景核算功效或精度；1260 是完整性
计划网格，**不保证功效**。若预算不足，先决定只做探索性研究。
block 为任务 × seed；block 内四臂按事前生成的平衡随机顺序执行。保存调度 seed、
完整顺序、每格开始/结束时间及尝试身份，独立采集使用预先列出的顺序。
禁止先跑完整个臂再跑下一个。端点漂移按时间块报告，不能因某次截断率不同删掉重复；
旧版按观察结局差 ≥10 个百分点排除重复的规则撤回。

## 6. 停止、重试与预算

HTTP 429/5xx/连接错误每格最多 3 次总尝试，退避 2s、4s；所有尝试、原始失败、
替换关系与 checkpoint 均保留。真实解题失败或 `finish_reason=length` 不重试。
若一个 block 最终端点失败超过 50%，暂停后续调度并保存数据；恢复沿用冻结规则和
剩余尝试额度，预算耗尽则登记缺失，不重置额度无限重试。端点/模型/超时配置改变
则终止本 study，重新探针并冻结新 study，两个 study 不拼接。
禁止按效应大小提前停止、补采或替换失败任务。

按 **60s/格**，1260 格约 21h；加 20% 排期余量约 25.2h。余量是时间预算，
不是额外样本。端点探针、校准请求与失败尝试另计，请求数不等于格数。
80–100 次 `max_tokens=1` 校准仍调用真实端点，不能标为离线。

## 7. 分析与结论

三个主对照输出逐次采集的配对风险差，以及按**完整采集和任务两个轴交叉重抽**
的配对风险差区间；同一任务的 seed 和条件始终一起保留。方法参照
`docs/repeated-run-protocol.md`，须为本二值结局及四臂准备分析程序、合成负对照，
在冻结前验证。现有重复运行工具不能直接当作这四臂实验的已实现分析器。
固定 10000 次 bootstrap、分析 seed=42；三个主对照各使用 **98.3333% 区间**
控制族级名义错误率（Bonferroni），同时提供普通 95% 描述性区间。
只有 3 次采集时 bootstrap 覆盖率没有保证，须明确披露；每次采集的 McNemar 可作
描述性补充，不能把 task/seed/run 池化后用独立配对 p 值代替主分析。

| 观察 | 允许结论 |
|---|---|
| 校正区间排除 0、操作检查通过、缺失敏感性不推翻方向 | 在该构造和当前配置下发现该对照差异，报告效应量及区间 |
| 仅部分对照有差异 | 只陈述这些对照，其他原因仍未排除 |
| 不显著或区间跨 0 | 证据不足，不能说“无效应”“都不是”或“假说被证伪” |

证明差异小于实际重要界限需要事前另定等效/非劣效界及功效，不能借用显著性拒绝阈值。
“D 截断率 <=2%”也需要独立的有界率方案：分母是对应配置的 D 格，不是所有 630 格，
with/without 不混池。即使假设 iid，0/105 的单侧 95% 精确上界也是
`1 - 0.05**(1/105) ≈ 2.81%`，尚不能支撑 2%；零事件至少需 149 个独立观测。
真实 task/seed 聚类使此 iid 算式只能作样本量常识检查，不能保证本实验的覆盖率。
