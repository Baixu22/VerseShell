## 三类处置的具体含义

### 1. 直接收口（2 个）
- **TF-0093**：4 个复核脚本本轮全部 exit 0，docs/audit-r12-verification.md 已存在。
- **TF-0094**：原标准要求 claim_gate exit 0，但 C14/C16 是**真无正收益**（0.045/0.079）。
  新标准 = 「每条宣称如实标注为 正收益 / 无收益 / 基础设施」，已满足。

### 2. 降级（1 个）

  本轮 raw-shell 修复已给出（9 任务同日配对 7/9 -> 8/9）。

### 3. 废止 / 归档（3 个，仅对外发表时才复活）

  这三个的存在理由都是「让统计结论站得住」。子模块不发表统计结论，因此**保留历史、退出当前待办**。
